科技作品 — 文件包存放目录
==================================

把每个作品的完整代码打包为同名 zip 放在此目录，
页面上"下载完整文件包"按钮会自动指向对应文件。

文件名对照（与 showcase/data.js 中 id 一致）：
----------------------------------------------------
csv_dashboard.zip   →  通用数据可视化大屏
cloud_music.zip     →  Jack 云音乐网站
photo_wall_3d.zip   →  3D 回忆照片墙
pdd_wheel.zip       →  拼多多一刀暴富转盘
hero_blindbox.zip   →  英雄盲盒十连抽
video_workshop.zip  →  热歌短视频工坊

如果文件尚未上传：
  - 页面会自动显示"文件包待上传"虚线提示卡（不报错）
  - 打包完成后把 zip 放入本目录即可，无需修改其他代码

部署到 GitHub Pages 注意：
  - 单个文件超过 100MB 需要使用 Git LFS
  - zip 后缀文件默认不会被 Git 忽略，直接提交即可
